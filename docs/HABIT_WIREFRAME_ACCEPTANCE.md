## 需求與邊界

- 三習慣固定，可更正名稱、改今天與未來日期及未來用量；單位與用途不替換。前端提示名稱僅更正，不宣稱能自動判斷文字是否改變習慣本質。
- 用量依目標固定時區隔天生效；今天、過去標準及已保存投入／積分不回算。同日最後確認值覆蓋明日版本，前後內容留在回顧快照。
- 新用量需有明天起的安排日期。預計總量按日期版本加總，舊明確總量不重寫。截止日當天無後續安排時拒絕無效修改。
- 沿用權限、交易、版本與重送去重。跨午夜重新核對生效日；取消不寫入、失敗保留輸入、衝突不自動升版重送。
- 005 遷移新增初始用量版本，不重寫原欄位或舊 migration。對舊結構副本逐表核對原值、完整性及外鍵；未定開始日的舊標準不猜日期。
- [完整原型](../collaboration/flow-wireframe/index.html)以獨立虛構狀態展示全流程；未串接服務明標模擬，沒有正式 API 呼叫。[操作與限制](../collaboration/flow-wireframe/README.md)。
