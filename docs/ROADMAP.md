1. 確認正式貢獻單位、部分完成粒度、歷史更正及撤銷規則；目前支援使用者輸入正數，最多六位小數。

5. 決定主動結束、恢復、完成後更正，避免擅自建立正式狀態轉換。
6. 同一真實事件的多草稿／附件辨識、人工合併／拆分、來源撤回；目前保證提交／草稿去重，不宣稱已解決語意去重。

## 正式系統

- 現有程式庫為 asixtw/life-world；後續以此版本接續開發。正式部署與團隊技術契約仍須確認。
- 第一輪線上試用沿用帳密，補邀請、登入保護及一次性復原碼，維持 owner 與成熟密碼雜湊；正式受管身份與第三方供應商留待後續，不把舊建議當成這輪強制整合。
- PostgreSQL 為暫定目標，依已驗證的不變條件移植 repository／migration，驗證併發與資料匯入，不能只換連線字串。React 前端先依同一 API 契約及獨立元件展示逐段移植。
- 使用受權限保護的雲端物件儲存、上傳限制／掃描／重試、保留期限及刪除策略。現有 BLOB 方案適合本機驗證。
- 接入真實 AI provider、設定與金鑰管理、輸出 schema／來源、錯誤與成本測試；維持候選與人工確認的界線。
- 人物星圖／收藏冊、360° 四維度、來源、衝突與互動事件已在 v0.2 完成；真實 AI 小劇場、夜間關懷與 Quiet UI、正式動效及 Figma 對齊接續處理。
- 多人參與／提及、人工配對、來源定位／展示撤回、焦點查詢、返回與人物卡串接已在 v0.3.0 完成。後續可評估全站 Evidence Viewer、名片共用校對、語音／AI 提取、收藏故事、跨刷新探索歷史、3,000 人及實機量測，不自動納入本輪交付。POC 對外展示範圍仍需團隊確認。
- 排程的下一版採起始日起一個月為預設、每週規律為選用；互動月曆、單日例外與歷史版本另項實作，本次仍保留舊週規律與 28 天預覽。
- 正式備份／還原演練、CI、容器或部署設定、監控與操作文件需依團隊環境落實；未建立指向未知服務的假部署設定。
