### 第三／第四步操作路徑

1. 登入後開 **http://127.0.0.1:8198/#record**，輸入合成原文及日期；保持「直接使用我的原文」。
2. 第二步可選「隔離測試目標」及活動數量，也可不關聯目標。
3. 第三步選既有人物或「＋新增人物」，**自行選互動／參與／提及**。展開每人的「補充這次了解的人物資訊」；選興趣/飲食/專長/習慣/生日/任職，輸入內容、來源與證據，再按「加入待核對項目」。多人逐人獨立。生日可只填月日；任職可選新增或原有任職，不直接覆蓋其他歷史。
4. 按「檢視並確認」。點每張人物卡，在預覽逐項勾選採用或按「本次不保存這項」；查看來源。完成檢視不是正式保存。卡片會顯示採用/排除數。
5. 核對人物角色後按「我已核對，確認保存」。到人物詳情查看生日、任職、四維資訊與來源。若未處理完，按「保存核對草稿並離開」，之後由草稿繼續。
