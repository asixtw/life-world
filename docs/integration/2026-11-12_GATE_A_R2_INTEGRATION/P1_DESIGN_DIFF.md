## 尚未與示意完全相同，不能假裝已完成

1. **R2示意可於第一步立即產出模擬摘要；正式產品不使用該模擬。** 第一步AI僅保留選用意圖，直到第三步完成、候選草稿來源版本固定後，第四步才透過既有`DraftAIUI`取得/核對範圍授權、呼叫真實既有API。這避免另造未保存草稿的AI通道、跳過四步或沿用錯誤來源授權。此時點差異需Owner審閱；未自行宣稱完全像素/時序一致。
2. 本機一般候選未開放真Gemini/辨識能力；UI正確顯示不可用並保留手動路徑。AI授權UI回歸使用明示Provider替身與真本機PG，不冒稱真Gemini。
3. 本輪沒有實機Safari/Android相機、真Google升級聯合驗收。PR22安全交易未改；Guest文字仍可獨立完成。不能用這組Chromium結果替代正式環境驗收。
4. 多素材的真實預覽/校對與錯誤控制比示意檔案按鈕更完整；額外選填內容採收合，不為外觀刪除來源或必要防護。

本輪不新增Schema、正式權限、背景AI、劇場或新登入系統。Gate A仍未核准；Gate B/C/D不由畫面測試自動解鎖。
