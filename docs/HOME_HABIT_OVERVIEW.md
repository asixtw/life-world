# 首頁三習慣摘要｜本輪實作與驗收

更新：2026-11-03。本機原生 App 與完整流程 Prototype；未 Commit、Push、合併或部署。

## 已實作

- 世界首頁以 Lumi ＋目前挑戰呈現；目標名稱、狀態、三個習慣緊湊列、主要記錄與次要詳情入口。手機單欄、桌面雙欄。
- 每列讀取 `/state` 的 `progress/target/unit`，保留 Decimal 字串精度與超量；使用伺服器 `today`、目標時區、期間及日期求下一安排。不呼叫完整 Dashboard 或逐日 calendar API。
- 進行中主要記錄；待回顧主要回顧、次要記錄；待補設定引導補齊；無目標引導建立；多個未結束目標要求整理。不完整資料不虛構第三習慣或修改目標狀態。
- 無後續安排、未知排程、讀取失敗分別呈現；錯誤保留 Lumi 與導覽、可重試。換 owner 清除舊世界快照與 Dashboard 快取。
- 合併舊「目標花園／今天一小步」重複區塊；保留待辦、伺服器草稿、交會／人物入口。首頁隱藏積分，不改帳本與其他頁既有回饋。
- 正式 App 沿用 CSS Lumi；Prototype 沿用房間、美術、Quiet 及虛構資料，不接外部 AI。
