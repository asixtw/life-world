## LW-BASE-001｜同一個起點

- **審查者：**全端。**輸入：**[現況基準](BASELINE.md)、既有工作目錄與演進紀錄。
- **交付物：**來源快照、受保護程式 SHA-256、文件入口與差異說明。
- **完成條件：**解壓後產品指紋吻合，能辨識本機變更與 Git HEAD 差別；不含資料庫、憑證、虛擬環境或真實資料。
- **依賴：**無。**阻礙：**尚未交由夥伴核對共同發布 commit；本次使用者已授權發布，私有備份仍排除。

## LW-UX-001｜共同流程

- **審查者：**使用者確認產品，全端確認可實作性；資料夥伴核對案例。**輸入：**[流程與狀態](FLOWS_AND_STATES.md)、原圖對照與現有 API。
- **交付物：**一般／夜間共用流程、排程與錄音狀態、例外退路及待決登記。
- **完成條件：**每個入口、主要操作、返回及失敗有去處；新提案不被當作既有 API。
- **依賴：**共同基準。**阻礙：**月份續期／月底規則、素材限制等提案仍需確認；不阻止沙盒展示。

## LW-TECH-001｜技術契約

- **審查者：**使用者確認範圍，資料夥伴核對模型。**輸入：**[完整指令](PROMPT_TECH_001.md)、現有 API 與狀態規格。
- **交付物：**API／schema 差異、遷移與回退、GCP 服務分工、認證與工作佇列契約、風險及工時資訊。
- **完成條件：**前後端對欄位、權限、重送、錯誤與來源一致；未定項明列阻擋點。
- **依賴：**共同基準。**阻礙：**尚未提供 GCP project／區域／可用權限及可投入時間；審查可先進行。

## LW-UI-001｜第一包元件

- **審查者：**使用者看體驗，全端看程式與介面。**輸入：**[完整指令](PROMPT_UI_001.md)、[狀態規格](FLOWS_AND_STATES.md)。
- **交付物：**獨立 React＋TypeScript 展示、參數／事件、驗證紀錄及手機／桌面截圖。
- **完成條件：**正常、錯誤、停用、載入可操作；錄音權限／試聽／重試等模擬狀態標示清楚；不修改正式資料與交易。
- **依賴：**共同基準。**阻礙：**夥伴的 IDE／Codex／本機執行環境與可投入時間未回報；無環境時先交規格，不能標程式完成。

## LW-DB-001｜只讀核對

- **審查者：**全端。**輸入：**[資料核對指令](PROMPT_DB_001.md)、現有 schema／測試。
- **交付物：**關聯圖、SQLite 專屬行為盤點、PG 映射、遷移與恢復測試案例、只讀差異報告。
- **完成條件：**完整保留 owner、ID、精確貢獻、來源與積分；不把 SQLite 測試當 PG 驗證。
- **依賴：**先完成 UI 第一包；技術審查可補充契約。**阻礙：**PG 測試環境未建立，先交設計與只讀證據。

## LW-CORE-001｜核心旅程整合

- **審查者：**全端；使用者驗收體驗、資料夥伴獨立核對。**輸入：**通過審查的流程、API、元件及遷移方案。
- **交付物：**React 核心頁、PG 適配／遷移、登入續作、月／週排程、多模態草稿與夜間共用流程。
- **完成條件：**登入至再次回讀完整可走；確認交易、權限與重送通過真實 PG 測試；新功能及既有人物／交會／小劇場無退化。
- **依賴：**LW-UX／TECH／UI／DB 相應契約已審。**阻礙：**尚未開工；AI 實際辨識另需指定端點與服務設定，不預設廠商。

## LW-INFRA-001｜容器與 GCP

- **審查者：**使用者核對試用範圍，資料夥伴見證還原。**輸入：**LW-TECH-001 結論與可建置程式。
- **交付物：**容器建置、測試環境、Cloud Run／Cloud SQL／私人 Storage、工作佇列、秘密設定、CI 與回復文件。
- **完成條件：**乾淨建置、HTTPS、重啟／部署不丟資料、素材權限、備份還原與新舊版回復經實測。
- **依賴：**技術契約與 GCP 資訊。**阻礙：**尚無環境細節，不建立猜測 project 的假部署。

## LW-ASSET-001｜圖片與插畫

- **審查者：**使用者確認視覺，全端核對檔案與載入。**輸入：**核准元件風格與素材需求單。
- **交付物：**候選圖、實際資產、尺寸／格式／透明背景／大小／來源與製作工具清單，放入實際畫面的預覽。
- **完成條件：**與現有 Lumi／風格一致；可讀文字與 UI 仍用程式呈現；不任意替換角色；有素材使用依據。
- **依賴：**UI 第一包完成與需求確認。**阻礙：**尚未指定素材清單及工具可用性。

## LW-AUDIO-001｜音效

- **審查者：**全端。**輸入：**產品確認的播放時機與實際音效工具。
- **交付物：**事件／檔案對照、靜音／夜間／減少動效行為、格式／長度／音量與來源清單；製作交由屆時指定夥伴。
- **完成條件：**核心操作不依賴音效，夜間無聲；真實音檔與播放驗收齊全；不把 ChatGPT 能力當作已取得音檔。
- **依賴：**核心流程穩定。**阻礙：**後期項，工具及需求未定。

## LW-QA-001｜回歸與試用

- **審查者：**全端確認發布條件，資料夥伴獨立驗證。**輸入：**已整合測試環境、[整合清單](INTEGRATION_REVIEW.md)。
- **交付物：**測試結果、手機／桌面及實機操作、缺陷、5–8 人首次使用觀察與一週回訪紀錄。
- **完成條件：**能完成首筆紀錄、再登入找回、理解 AI／確認／來源；阻擋問題修復且重測，無法驗證項明列。
- **依賴：**核心流程及部署就緒；邀請與觀察需實際安排。**阻礙：**尚未招募或對外聯絡，不能以本文件宣稱使用者驗證完成。
