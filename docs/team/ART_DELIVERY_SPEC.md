## 2. P0｜完整操作元件

### 2.1 共通設計與工程規則

- 色彩沿用 [tokens](../../app/static/tokens.css)：紙色 `#f7f8f2`、白色 `#fffefb`、文字 `#334431`、主綠 `#526f4d`、薄荷 `#eaf0e1`；其他值沿用現有 [樣式](../../app/static/styles.css)，新增值附用途。
- 沿用字體、留白、圓角、陰影、筆畫及人物／來源的既有資訊層級，不另換品牌或角色。
- 日間、Quiet、減少動效均可展示；Quiet 保留文字可讀性並降低裝飾亮度及動態刺激。
- 手機操作目標至少 44×44 CSS px；支援鍵盤、可見焦點、長文字、螢幕閱讀器及手機 safe area。
- 元件接受 typed props／事件，由容器管理資料與服務；展示控制列、虛構資料及 fixture 標示留在 gallery。
- 通用按鈕傳遞原生 `type、disabled、aria-*、事件、ref`，保留表單及目前分頁語意。
- CSS 限定元件命名空間或作用域，避免 gallery 的全域樣式覆蓋正式 App。

### 2.2 基礎元件清單

| 類別 | 必交元件／狀態 |

| 按鈕 | 主要、次要、文字、圖示、危險、切換；正常、hover、按下、焦點、停用、載入、成功／失敗 |
| 輸入 | 文字、長文、密碼、數字、日期時間、搜尋、下拉、checkbox、radio、switch；空白、填寫、說明、錯誤、停用、載入 |
| 導覽 | 世界／目標／紀錄／關係四分頁、頁內 tabs、返回、breadcrumb、目前位置 |
| 卡片 | 目前目標、習慣、人物、故事、經歷、附件、私人模擬；多角色／標籤、星標、統計及進度 |
| 面板 | Dialog、BottomSheet、來源抽屜、Toast；開啟、關閉、焦點返回、長內容捲動及錯誤 |

### 2.3 月份／週排程

- 呈現實際日期，預設月份檢視，可切換週；切換不清除安排，月份不等於目標預設期限。
- 顯示年月、星期、今天、已安排、未安排及不可編輯日期。
- 提供上一期／下一期、星期快選、平日、每天、清除及單日調整；星期快捷明示作用於整個目標可編輯期間。
- 日期限目標期間內，修改時保留過去日期與歷史標準；顯示安排天數、每次預期量及變更摘要。
- 「已安排」與「已完成」用不同文字及視覺；安排不能直接更新進度或獎勵。
- 維持三個習慣、名稱僅更正、單位／用途固定；未來用量隔天生效，依目標固定時區及既有版本衝突規則呈現。

輸入：`startDate、endDate、selectedDates、cycle、cursor、disabledDates`。
事件：`toggleDate、selectWeekday、applyPreset、clear、changeCycle、changePeriod`。

### 2.4 錄音、附件與校對

依最新版 [MEDIA_COMPONENT_CONTRACT](MEDIA_COMPONENT_CONTRACT.md) 製作，保留現有 App 的人工確認規則。

| 元件 | 必交操作與狀態 |
|---|---|
| 錄音 | 待開始、請求權限、錄音中／時長、停止、取消、可選試聽、明確上傳、處理中、失敗及重試 |
| 附件 | 圖片、截圖、拍照、名片、音檔入口；本機預覽、大小／格式、移除、取消、處理及重試 |
| 校對 | 原始辨識文字、可編輯文字、核對勾選、加入經歷／複製文字、來源展開 |
| 草稿 | 正在保存、已存此裝置、保存失敗、伺服器文字草稿、本機素材接續入口 |

- 流程為「錄完 → 明確上傳並轉文字 → 校對」；試聽非必經，不做預設即時轉錄。
- 選取、預覽或停止錄音不自動上傳；音訊不自動播放。
- 未知進度用不定進度，不製造百分比；格式／大小由容器能力傳入，不把候選限制硬寫為正式政策。
- 權限拒絕、無裝置、不支援格式、服務未設定及儲存失敗都有文字退路。
- 原素材、辨識原文及手動修改分開；修改取消先前核對，晚回應不覆蓋編輯。
- 取消／移除後，晚到回應不復活素材；停止／切頁清理麥克風、請求與預覽資源。
- 名片使用人物資料草稿語意，不直接成為經歷、人物、見面或成果。
- 元件不自行確認正式資料、增加進度或發放獎勵；fixture 明示模擬。

### 2.5 操作圖示

核對並補齊一致 SVG：世界、目標、紀錄、交會、返回、前進、關閉、新增、搜尋、設定、星標未選／已選、麥克風、停止、播放、暫停、上傳、圖片、相機、名片、音檔、重試、移除、來源、日曆、確認、警示、複製、草稿、安靜、聲音開／關。

交付 24×24 基準 viewBox，支援 `currentColor`，附 16／20／24／32 px 展示。圖示按鈕須有文字或可讀標籤；按鈕 PNG 不代替可操作元件。

## 3. P1｜美術、角色、世界與動效

### 3.1 App 代表圖

| 資產 | 必交輸出 |
|---|---|
| 主圖示 | 1024×1024 PNG；512、192、180、48 px 輸出，含 favicon |
| 分享圖 | 1200×630 |
| 方形代表縮圖 | 1024×1024 |
| 裁切展示 | 方形、圓角、圓形、明暗背景及小尺寸 |

保留 Lumi 識別，小尺寸仍清楚；必要 UI 文字由介面呈現。既有原生向量交可編輯 SVG，不以包 PNG 的 SVG 冒充向量；點陣原稿保留原格式。這是 Web／設計交付，不宣稱已上架原生 App。

### 3.2 Lumi 六種姿勢

| 狀態 ID | 用途 | 視覺要求 |
|---|---|---|
| `idle` | 日常陪伴 | 穩定、自然 |
| `welcome` | 返回世界 | 溫和歡迎 |
| `listening` | 記錄／整理 | 專注陪伴 |
| `quiet` | 安靜模式 | 平靜、低刺激 |
| `confirmed` | 真實經歷確認 | 輕量喜悅 |
| `celebrate` | 目標成果完成 | 明確但不誇張的慶祝 |

葉片、身形、眼睛、嘴與翅膀保持一致；不加入死亡、責備或衰弱懲罰表情。交透明原稿、512／256／128 px 顯示版及一致角色錨點；已有合格姿勢沿用。Lumi 在首次目標經後端確認後才出現，孵化前不以其第一人稱說話。

### 3.3 目標蛋與首次孵化

必交狀態：靜置、微光、初裂、裂紋加深、破殼、Lumi 出現、完成定格。穩定狀態 ID 與既有元件有差異時附映射，不直接破壞舊引用。

可組合圖層：蛋體／裂紋、左蛋殼、右蛋殼、獨立 Lumi、光效、地面陰影。共用畫布及錨點，交透明 PNG 與適當顯示版；完成合成圖可預覽，動效仍須可獨立組合。

元件提供開始、完成、跳過、取消、重播及靜態替代。首次成立以伺服器確認為前提；後續目標不重複當成 Lumi 首次誕生。回執／角色上下文改變時取消舊動畫，避免舊計時器對新回執發出完成事件。

### 3.4 正向回饋

1. 經歷確認：養分抵達、短暫回饋及 `confirmed` Lumi。
2. 習慣累積：依伺服器資料呈現進度變化。
3. 目標完成：成果回顧、`celebrate` Lumi 與完成定格。

一般回饋用無蛋殼 Lumi。視覺只顯示結果，跳過、重播、關閉及載入失敗不影響帳本，養分或進度以唯一真實回執為準。

### 3.5 房間／世界背景

交同一房間的日間與安靜版：

- 溫暖簡潔 2D，包含牆面、地面、窗景及少量家具。
- 分層為背景、家具、前景裝飾、角色落點／陰影；Lumi、蛋及 UI 文字獨立擺放。
- 兩版同構圖及角色落點，切換不跳位；安靜版降低窗外亮度及裝飾刺激，保留室內辨識度。
- 提供角色安全區、文字避讓區與手機裁切示意。

輸出：橫向原稿 1920×1440、1280×960 顯示版；直向構圖 768×1024。圖層含透明版本，背景可用優化 WebP；保留原稿，頁面依尺寸載入顯示版。本批是固定場景，家具購買、擺設編輯及經濟系統另行規劃。

### 3.6 人物與情境美術

- 十五位頭像、三組封面，對應 [LW-SIM-001](PROMPT_SIMULATION_001.md) 的既有人物／情境 ID。
- 頭像：1024 方形原稿、256 顯示版及圓形裁切。
- 封面：1600×900、800×450 顯示版及手機裁切。
- 真實歷史人物的藝術詮釋與虛構角色標示清楚；不自行改人設。
- 全部標 `demo`，不混入真實收藏、來源、互動／見面、進度或積分；正式版保留及封測入口仍待確認。
- 已交付圖像先核對一致性、裁切及來源，合格者沿用。

### 3.7 空白狀態與轉場

空白狀態：尚無紀錄、尚無人物、搜尋無結果、服務暫時不可用。交簡潔 SVG／插畫、文字及下一步入口，不以悲傷角色施壓。

轉場：分頁、卡片展開、面板進出、故事切換、人物聚焦、處理完成、首次孵化及返回。可獨立重播，附 duration／easing／loop／取消／完成事件；圖序需實際 frames／atlas 與 metadata，影片只作輔助。

製作預設：微互動 120–180 ms；一般切換 180–280 ms；正向回饋 400–800 ms；首次孵化總長 3–5 秒且可跳過。Quiet／減少動效用短淡入或立即靜態結果。反覆進出清除計時器、音效及 overlay，每次完成事件最多回呼一次，動畫失敗仍能繼續操作。

## 4. P2｜完整音效包

以下是製作預設，先交候選供 Boyi 聽審；不代表正式 App 已啟用聲音。

| ID | 用途 | 建議長度 |
|---|---|---|
| `ui-tap` | 特定主要操作的輕觸回饋 | 0.03–0.10 秒 |
| `draft-saved` | 明確保存成功 | 0.15–0.35 秒 |
| `experience-confirmed` | 真實經歷確認成功 | 0.4–0.8 秒 |
| `first-hatch` | 首次 Lumi 誕生 | 1.5–3 秒 |
| `goal-completed` | 目標成果完成 | 0.8–1.5 秒 |

- 溫和、短促，避免尖銳警報、責備語音及突兀音量；五種各交兩個候選，Boyi 選定後整理正式版本。
- 原稿 48 kHz WAV，另交 AAC／M4A 及 Ogg 播放版本；Jerry 審查實際瀏覽器相容性。
- 峰值不削波，音量相近，首尾無爆音；附工具、生成／取得方式、使用依據、時長與大小。
- 聲音預設關閉、使用者主動開啟，仍為候選預設；Quiet 強制無聲。
- 載入／播放失敗不阻擋操作；成功音效依真實回執播放，重複回應不重播。
- 示範播放與正式資料分開，頁面載入不自動播放。

歐桑先確認可用工具與輸出權限；不能產出實際音檔時明列阻礙，交 Boyi 協調，該項維持未完成。不因 Pro 訂閱推定已取得音效工具、API 或使用權。
