# 全流程原型｜表單阻擋與修正引導檢查

日期：2026-11-02。範圍限[全流程 Prototype](../../../collaboration/flow-wireframe/index.html)，不是正式 App 的 UX 驗收。本輪未 Commit、Push 或部署。

## 問題與規則

經歷空白時雖已有頁首文字，但長頁面上的使用者可能看不到；瀏覽器原生 required 又可能只顯示短暫系統泡泡。兩者均不足以告訴使用者下一步。

新增 `validation.js` 共用處理：

- 欄位旁說明與主要操作區摘要；錯誤不只靠顏色。
- 聚焦並捲到需修正位置；收合的 details 先展開。
- `aria-invalid` 與 `aria-describedby` 連結提示；修改後清掉該欄舊錯誤，保留原本提示關聯。
- 原生 required、數值上下限、精度及格式錯誤統一為繁體中文文字，保留原生限制，不降低標準。
- 不清空輸入、不自行確認、不改進度；保存草稿及取消保留仍允許未完成內容。

## 已檢查與處理

| 流程 | 發現／改善 |
|---|---|
| 經歷輸入 | 空白無附件時提示輸入或選附件；附上「可先存草稿」退路 |
| 手動整理 | 沿用內容與發生時間檢查，避免繞過正式整理的必填限制 |
| 目標與習慣 | 必填說明、純空白名稱、成果描述、截止日、數量／單位、未排日期的修正引導 |
| 月份規律 | 未選任何格子、無效截止日，指向規律區或日期欄 |
| 經歷確認 | 摘要空白與未勾確認分開說明，對應到正確欄位 |
| 名片／新增人物 | 必填稱呼、純空白、同名人物與未勾確認有提示；不擅自建立人物 |
| 後續任務 | 必填任務名與日期沿用欄位限制；空白名稱另檢查 |
| 目標回顧 | 延長日期、結束確認及成果佐證導向對應輸入 |
| 夜間設定 | 起訖時間相同時說明修正位置；保存草稿不受限制 |
| 劇場 | 情境／人物選取錯誤、發言空白、轉錄未核對、Lumi 問題空白提供就近提示及焦點 |

重要區別：未確認的人物／貢獻屬可選項，沒有勾選時可依既有規則不採計，不應一律把它們變成必填。未排日期則是習慣建立必要條件，仍阻擋下一步。
