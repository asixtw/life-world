# LW-SIM-001｜十五位擬真人物與完整可玩模組

日期：2026-10-28。**主責歐桑；產品／內容驗收 Boyi；型別、資料與整合審查 Jerry。**Boyi 已確認本次任務通知完成。狀態：任務已定案、成果尚未驗收。

## 1. 目標與範圍

三組各五位，交付可追溯來源的人物、可玩劇場、研究材料及通用整合介面。目標是未來研究真人情境／對話模擬；本次先測角色一致性、來源使用與自然度，不能以合成資料內一致就宣稱能預測實際遇到的人。

完整獨立模組由歐桑交付；正式 App 接入由 Jerry 把關，Boyi／Codex 可協助實作。資料生成、Prompt／檢索、即時 API 與權重微調分開記錄；沒有實際跑訓練不寫已訓練。

本包是測試／POC／封測用 demo；資料及匯出記錄 `usage_scope=demo`、適用通道、版本與正式版未核准狀態。正式版是否保留待 Boyi 評估，不能預設進正式人物庫。封測「人物劇場 → 情境體驗（示範角色）」為待確認入口提案；本任務不直接新增正式 App 路由或對所有使用者開放。

## 2. 本版角色與場景

名單沿用前輪規劃作本版基準。角色／場景實質修改由 Boyi 確認，不默默縮減五人數量。

| 組別／pack ID | 五位人物或角色 | 兩個可玩主場景 |
|---|---|---|
| 三國策略 `three-kingdoms` | 曹操、劉備、諸葛亮、孫權、周瑜 | 赤壁前夕策略／結盟；假設糧運／撤軍協商 |
| 國際協調 `international-dialogue` | 美方代表、伊方代表、中立調停者、國際組織觀察員、航運方代表 | 假設停火與議程；航運安全／查核協商 |
| 哲學辯論 `philosophy` | 蘇格拉底、孔子、莊子、尼采、柏拉圖 | 成功與自由；承諾、責任與個人選擇 |

三國區分史料與文學創作；哲學跨時代圓桌本身是創作，觀點引作品／可靠來源，轉述標記轉述。國際組是職務角色與有日期的公開立場，不捏造現任真人私下意圖或秘密談判；協商明示假設，不冒充正在發生的新聞。

## 3. 每人必交資料與契約

以版本化 JSON／JSONL、schema／TS 型別與可讀說明交付；JSON 不塞註解。所有 ID、引用與資產可解析。

| 類別 | 必交內容 |
|---|---|
| 識別 | 穩定 persona_id、pack_id、顯示名、角色種類／版本，不每次重生成固定內容 ID |
| 背景／時間 | 有來源的背景與公開立場、場景時間／知識範圍，不讓赤壁前角色知道後續戰果 |
| 來源 | 重要主張有 source_refs，附作者／機構、篇章或位置、日期（不詳就明示）、網址或書目；不可編造引用 |
| 證據層級 | 來源事實、文學記述、角色詮釋、設計假設、生成劇情、未知分開；衝突不偷偷覆寫 |
| 演練設定 | 當下目標、條件／限制、溝通方式、可能讓步與反例；非來源支持者標假設 |
| 多輪示例 | 每人至少三段，呈現支持／質疑／有條件同意等不同反應；標生成示例，不冒充原話 |
| 保留評估 | 每人至少兩個新情境，附評分規則、可接受範圍與來源；參考答案與模型輸入分開 |
| 美術 | 頭像／alt／資產 ID，對應完整美術包，缺圖不得只放空路徑 |

最少十五人、四十五段多輪示例、三十個保留情境。這是本包數量，不是訓練足量或準確率保證；不為湊數複製同段或捏造事實。

## 4. 可玩模組與介面

- 三組皆可選角、看人物／來源、選場景、開始、分支對話、返回、重設、回顧及匯出模擬紀錄。六場景各至少三條實質不同路徑，全部有可到達的結束／回顧。
- 腳本模式完整可玩並明示預寫；即時模式由可替換 adapter 接指定後端。未設定端點就明示未設定並可改腳本，不把預寫冒充即時 AI。
- 提供 Persona、Scenario、DialogueTurn、SimulationSession、SourceRef、AssetRef 等型別／schema，adapter 輸入／輸出、來源引用、錯誤、取消、重試及匯出契約；Jerry 核對後再接正式服務。
- 不預設供應商、前端／Git 不放 key；不另建平行真實人物 DB。切換／重設不串錯 session，失敗及離開有退路。
- 模擬 fixture／命名空間與正式資料隔離，不呼叫正式確認、人物事實、見面／互動、貢獻或積分寫入；匯出標 simulation，不自動匯入真實經歷。

## 5. 研究與存放

在 `collaboration/ui-kit/` 內以 `content/` 放人物／場景、`evaluation/` 放保留案例與研究設定、`assets/` 放美術、`docs/` 放來源與交接；清單及展示互相對應。

- 歐桑逐位核對人物主張與來源，留下人工核對狀態；模型自產答案不是權威真值，AI 評審不替代人員及原始來源。
- 同一人物的新情境按事件／情境保留；研究新人物泛化另按人物隔離，換措辭的同一案例不能冒充獨立測試。
- 記錄資料、提示詞、生成模型／工具與評估版本，輸入不帶參考答案／未來結果。
- 真人研究另取得資料使用依據，先封存模擬再比對後續互動；本包只用公開來源及明示合成內容，私人真人資料不放公開 GitHub。
- 可參考[本人資料與保留評估研究](https://arxiv.org/abs/2411.10109)、[Eval4Sim](https://arxiv.org/abs/2603.02876)，不能搬用論文數字作本產品已達效果。
