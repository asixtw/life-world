## 1. 這輪要驗證什麼

使用者不靠逐步教學，能建立目標、留下每日過程、校對保存、回看人物及來源、沿交會找回故事，並體驗劇場。驗證「容易留下、找得回來、內容可信、願意繼續累積」；不以獎勵、填滿欄位或單次完成率代替持續價值。

封測不做積分、養分、兌換、商店、獎勵音效或獎勵資格計算。保留無懲罰的保存成功、初次 Lumi 出場、目標完成紀念與未達成旅程紀錄。目標／習慣的實際投入統計仍由人工確認，與虛擬獎勵分開。已有帳本及使用者資料不得為這項範圍調整而刪除、重算或修改歷史。

### 目標／日常規則不重新設計

一次一個未結束目標，固定三習慣；月為預設編輯檢視，可切週，不代表預設期限。實際日期、星期快選、單日調整及清除；日期安排只代表打算做。新用量按目標固定時區隔天生效；今天、歷史投入及原帳本不回算。到期先回顧，不自動判定失敗，不阻止保存經歷；待處理投入另行人工核對。詳細沿用既有目標規格。

## 3. 紀念品與人物關聯（本輪已確認）

- 目標完成後，在「已完成」收藏完成紀念；未達成則在「曾經挑戰」保存旅程紀錄，區分到期未完成／提前結束，不羞辱或扣分。
- 點進紀念品，只呈現目標名、期間、結果、回顧文字、三習慣投入摘要、基本數據，以及過程中的相關人物／事項摘要；**不是全部經歷、附件或資料表明細的集合頁**。
- 此為呈現範圍，不是資料刪除指令。原經歷、人物維度、來源、星標及故事關聯保留；素材留存政策另審，沒有新增自動刪除。
- 人物頁分頁仍叫「合作與目標」，區塊統一叫「相關目標」。關聯保留同一目標 ID，狀態標示「挑戰中／待回顧／已完成／已結束」；已結束另顯示原因。這是目標狀態，不是人物身分、關係強度或人物完成狀態。
- 開始下一目標不能把所有人物自動改綁新目標；只由新經歷或明確選擇增加關聯。歷史相關人物入口返回人物卡，仍可從共同經歷追溯原始內容。
- 完成摘要以結束當下已確認內容及使用者回顧生成快照；不捏造統計，不因後續人物資料修正改寫歷史摘要。未有對應資料者顯示「尚無已確認內容」。

## 4. 真實辨識與劇場的工程門檻

**真實語音轉文字及圖片辨識皆為封測必備。** 原型操作、假回應、預設 503 及手動替代不算達標。供應商仍未定；不得把這項決定解讀成指定 OpenAI 或其他廠商。

- 語音：權限 → 錄音 → 停止 → 可選試聽／重錄 → 明確上傳並轉文字 → 校對 → 草稿及正式人工確認。
- 圖片／截圖：選取或拍照 → 預覽／移除 → 明確上傳辨識 → 校對 → 明確套用。名片另走人物配對／新增草稿，不虛構見面或完成量。
- 超量、不支援、拒絕權限、逾時、服務失敗、取消、晚回應、保存失敗及刷新都有退路；保留既有輸入，晚回應不覆蓋編輯。正式格式、大小、時長由 Jerry 提技術可行值後審查，不把原型限制當正式政策。
- 私人筆記及全部模擬不得寫人物正式事實、真實互動、目標進度或舊獎勵帳本。真實人物演練先以來源與私人筆記為底，不能把推測當對方事實。
- 示範包沿用 [LW-SIM-001](PROMPT_SIMULATION_001.md)：三組十五位、六場景，腳本模式可完整玩；即時模式未接須明示，不偽裝即時 AI。這輪只確定入口與模式界線，角色內容仍由歐桑交付驗收。

真實資料能否用於封測、外部 AI 告知／同意、留存／刪除、實機格式及雲端政策仍是發布阻礙，不能因畫面定稿而視為已同意。Jerry 提案、Boyi 決定；封測前未完成則不發布真實資料版本。

## 8. v1.1｜個人多人物演練（Boyi 明確確認修訂）

2026-10-29。產品定位是個人第二大腦／私人演練；一位真人使用者可調動自己已建立的人物同場模擬，不是多人真人聊天室。此為 Boyi 對 v1.0 的明確範圍補充，未公告／發布／完成正式服務。

- **人物來源：**本人收藏冊全部已建立人物皆可搜尋／選取，不限目前目標、最近互動或預設示例；跨帳號人物不可讀取。沒有資料的維度顯示未知，不因選入劇場就補造個性。人物數量多時使用搜尋與分頁，不能為簡化 UI 截斷可選人物。
- **選角：**使用者逐一多選，至少一位才可開始；可維持單人演練，亦可選多位。全部可選不等於全部自動載入、送 AI 或每輪全部發言。正式單場容量由 Jerry 提案、Boyi 確認；本輪不偷設固定五人上限。
- **流程：**人物劇場 → 選擇人物 → 填演練情境／目的 → 預覽及選取可用來源 → 開始 → 指定回應對象／逐輪發言 → 結束回顧。人物卡進入時帶入該人物，仍可增加其他已建立人物；不重建人物或生成正式群組關係。
- **發言：**每則顯示發言者 ID、稱呼與模擬標示；使用者選當輪回應對象，預設先一位回應，不自動讓全體互相循環。後續可換另一位繼續；系統及其他角色的話不可冒充使用者或真實人物原話。
- **情境與證據：**本人補充的假設情境、已確認來源、模型生成各自區分。只使用本次選取且有權限的資料，缺少來源就明示資訊不足；不得將一人的私密內容自動帶入另一人的提示。正式外部處理仍待資料使用政策核准。
- **保存：**選角草稿、情境、當輪未送文字、逐輪對話及回顧存獨立私人模擬上下文；返回、刷新、失敗保留。取消／重設需明示影響範圍，不刪真實人物。更換成員或情境開新場；既有對話保留，不把新成員偷偷套回歷史。
- **示範角色：**三組各五位仍依既有任務，組內可多選同場；與本人收藏冊分區，不自動混場、不匯入正式資料。跨組混搭不列本輪必要功能。
- **最小整合介面（待 Jerry 審查，尚無新 API／表）：**模擬 session 帶 `session_id、mode、participant_ids、scenario、source_refs、turns`；每輪帶 `turn_id、speaker_id、recipient_ids、text、is_simulation`。後端以 owner 核對每個人物及來源；參與者集合綁定場次，重送／逾時不重複新增回應。未選服務商，無前端金鑰。
- **限制：**原型以預寫回應顯示對象及輪次，未接真實人物模型或來源選取服務。原有四用途不刪；訊息仍只複製、相遇後回顧仍需另記真實經歷。全部模擬不改人物維度、關係、見面次數、目標、紀念品、積分或獎勵。
- **追加驗收：**空選擋開始、全人物可選、多選／移除、明確發言者與對象、未入場者不發言、取消／重試／刷新、資料隔離、跨 owner 拒絕與來源授權；真實 AI 與正式權限仍待工程驗收。
