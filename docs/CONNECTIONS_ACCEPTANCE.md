日期：2026-10-28（Asia/Taipei）。本輪依使用者最新指示完成整合後再做完整回歸；**交會取代星圖**，保留收藏冊、人物完整頁及世界／目標／紀錄／關係四導覽。原型與原始交接包未改動，未推送 GitHub。

## 已交付

- 故事由本人已確認經歷讀取，按人物焦點與時間分頁；中央呈現事件、參與者、提及者及其他故事。可返回上一步、保留當前故事／搜尋／捲動與展開，無下一段有退路。
- 來源使用底部抽屜，原文、摘要與使用者審閱分開，點提及可定位 Unicode 原文片段。明確提醒審閱不等於第三人證實、配對不代表出席或私人關係。
- 人工配對既有人物、分辨同名、略過／拒絕／取消／更正及歷史均保存 SQLite；刷新重讀，不只存在頁面。角色、配對與展示撤回有 owner、CSRF、版本及重送去重。
- 經歷草稿可整理多位參與者、直接互動與提及；同場不自動算互動或見面。事件合併不擴張每筆來源的人物名單，配對及更正不重發積分。
- 收藏冊與人物卡可進入交會；人物卡分列參與故事及已核對提及，原四維度／來源／目標／小劇場仍可操作。舊經歷可從待核對清單或紀錄內來源入口分類，不猜測參與。

## 體驗檢查發現與處理

| 問題 | 重現方式／影響 | 處理 |
|---|---|---|
| 核對頁返回遺失摘要及下一步 | 修改摘要／任務 → 返回原始草稿 → 再進核對，原修改被重設 | 保留同一草稿的頁面核對暫存；避開切頁鎖定後 FormData 排除 disabled 欄位的問題，並保留未保存旗標 |
| 慢查詢像卡住 | 請求未完成時只看到鎖住的舊畫面 | 超過 200ms 顯示載入回饋；成功及失敗都解除等待；清單／來源錯誤有重試與返回入口 |
| 同場故事在人物卡難找到 | 人物有參與但未直接互動，沒有互動事件可供原時間線顯示 | 人物頁另列實際參與故事及已配對提及，與事件統計分開 |
| 關閉來源可能丟更正 | 更正標題或角色但未保存，直接關閉／Esc | 保留輸入並提示明確捨棄；保存、取消、展示撤回均不重發積分 |
| 來源往返可能失去原入口 | 從交會進人物，再查看四維度來源後返回 | 傳遞原人物頁及探索返回路由；收藏冊維持原搜尋與選取 |

本輪旅程沒有觀察到無法完成的阻塞或 JavaScript 未處理例外；這只涵蓋列明案例與環境，不代表全部實機情境均無問題。

## 卡頓與效能量測

以真實 API 建立兩組隔離資料：4 人／3 段故事、300 人／103 段故事。390×844 Chromium headless，每條路由各三次，量測 hash 導覽到畫面渲染並繪製兩幀，報告中位數；不是正式百分位或負載測試。

| 路由 | 小量資料／本機 | 300 人／本機 | 300 人／150ms 延遲、1Mbps 下載、4× CPU 降速 |
|---|---:|---:|---:|
| 世界 | 16.6ms | 16.7ms | 33.0ms |
| 紀錄 | 16.7ms | 25.1ms | 58.9ms |
| 交會 | 25.1ms | 25.0ms | 240.8ms |
| 收藏冊 | 25.1ms | 42.3ms | 224.5ms |
| 新經歷 | 17.1ms | 16.8ms | 32.8ms |

本次觀察未發現超過 50ms 的主執行緒 long task，JavaScript 例外為 0；這不是固定 FPS 或手機實機保證。世界／目標等頁面多用已載入狀態，以上不包含首次開啟／整頁重新載入的時間。

300 人時，本機 API 往返中位數：`/api/connections?limit=8` 4.0ms、`/api/people?limit=12` 20.2ms、`/api/state` 37.2ms。交會查詢在 SQL 分頁；既有世界狀態與人物列表仍有全量組裝，後續擴到 3,000 人時應另做首次載入、索引與分頁優化，不能由本結果宣稱已支援該規模。

原始量測見 [performance.json](artifacts/connections/performance.json)，可在隔離服務用 [audit_experience.py](../scripts/audit_experience.py)重現。模擬網路與 CPU 不等於真實手機、網路抖動或多人併發。
