# 月份／錄音／附件／校對整合驗收

日期：2026-10-29。這次實作於既有 App；不是歐桑 React gallery 的完整合併，也不宣稱供應商或雲端服務已接通。具體介面、責任及限制見[整合契約](team/MEDIA_COMPONENT_CONTRACT.md)。

## 需求與邊界

- 沿用四主分頁、首頁 Lumi 及原有視覺；月份／週用同一組真實日期，排程不當成完成。
- 真實錄音：開始授權 → 錄音 → 停止 → 明確上傳轉文字 → 人工校對；試聽可選，絕不自動上傳或播放。
- 圖片／截圖／拍照／名片／音檔入口可本機預覽、移除、重試；原素材、辨識原文、手動文字分開。
- 本機草稿按 owner／上下文隔離，可返回、重新整理、保存及接續純素材；儲存失敗不宣稱已保存。
- 名片不自動成為經歷或人物，任何辨識／草稿操作均不更新正式進度及獎勵。
- 未設定服務、權限拒絕、取消、晚到回應、格式錯誤、容量不足、超量、跨帳號及提供者失敗均有退路。
- 不改資料庫結構、不選 AI 廠商、不引入框架、不部署、不 Commit／Push。

## TDD 與本輪證據

1. 先新增 `tests/test_media.py`，初次 19 項因端點尚不存在而 404 失敗；再實作真實能力查詢及無副作用辨識邊界。

## 本輪瀏覽器驗證內容

- 390×844、1440×844：選取不傳送；503 保留原文／素材；成功回應使用明示測試替身；未勾核對不可套用；套用後重新整理回讀。
- 保存草稿／正式確認前後，積分只有既有確認交易增加；核對頁可回看本機素材；較新伺服器草稿不被本機舊文字覆蓋。
- 麥克風拒絕／遲到授權取消；停止釋放音軌；不強迫試聽；失敗仍可再操作。
- 取消／移除後晚回應不復活素材；等待期間的手動編輯不被覆蓋。
- 儲存失敗、另一 owner、返回／繼續、純素材草稿從紀錄頁接續、不支援格式保留其他欄位；媒體暫存不可用不阻擋純文字保存。
- 月／週切換保留選取；日曆是實際月份且明示安排不代表完成。
