# 單一目標與三個習慣｜需求與驗收

2026-10-29 後續增量：開始挑戰後可更正習慣名稱、調整未來用量，依目標固定時區隔天生效；新用量及歷史分版、衍生總量按日期加總、舊投入不回算。詳見[最新驗收](HABIT_WIREFRAME_ACCEPTANCE.md)及[完整流程 Wireframe](../collaboration/flow-wireframe/README.md)。下方保留 v0.4 初次實作的歷史結果與截圖。

需求確認：2026-10-28；實作與驗收：2026-10-28～29（Asia/Taipei）。來源：Boyi 本次確認並要求實施的計畫。本文件先列驗收條件；實際結果於實作後補入，不預填通過。

## 需求

- 每個帳號只可有一個未結束目標（含到期待回顧、舊目標待補設定）。建立時必選截止日，設定三個習慣，每次預設 1 次，可改數量／單位。
- 建立分為名稱、成果與期限、三個習慣、總覽；本機草稿依帳號隔離，返回／取消／重新整理不丟失。全部確認才正式建檔，首次才孵化 Lumi。
- 習慣月／週排程使用真實日期，支援星期、平日、每天、單日與清除；至少一天且不超出目標日期。排程不是完成紀錄。
- 截止日包含建立時固定之目標時區的整個當天，翌日起待回顧；延長、成果完成或結束後才繼續。無未登入或失敗懲罰。
- 待回顧經歷仍可確認並按既有規則發一次獎勵；目標貢獻另外待處理，延長後逐筆明確確認，不自動補算、不再次發獎。
- 已完成／曾經挑戰可回顧，後者區分到期未完成與提前結束；不提供恢復、複製重試。歷史仍保留經歷、佐證與未採計資訊。
- 舊資料不猜截止日，舊多目標不自動刪除或結束；使用者逐一補設定／完成／結束，整理前禁止新增。

## 邊界與例外

- 空白名稱、少於／多於三習慣、零／負數／NaN／過大數量、重複日期、無排程、超界日期、截止日在今天之前、閏年／月底／跨年。
- 跨帳號、CSRF、版本衝突、雙視窗同時建立、相同請求重試、變更內容重用提交代碼；失敗保留草稿，不部分寫入。
- 到期、延長與確認同時發生時，交易內重新判斷；未採計項目的修改／確認具版本與去重，不使用經歷確認重做入帳。
- 延長必須超過原截止日且不能早於今天；排程只更新尚未發生的日期，既有貢獻及歷史日期／數量不重算。
- 目標時區在開始時固定；帳號改時區不移動既有截止日與紀錄歸日。紀錄的 UTC 時間與目標時區保留。
- 純讀取不自動改狀態或獎勵。已完成／結束目標不再接受正式貢獻，仍可保存不帶貢獻的經歷。

### 可重現命令

後端：

```bash
.venv/bin/python -m pytest -q --tb=short # 執行 API、交易、日期、相容與工具保護案例。
```

先在另一個終端機啟動隔離瀏覽器驗收服務：

```bash
.venv/bin/python -m browser_tests.clock_server --data-dir /tmp/lifeworld-goals-browser-20261028 --clock-file /tmp/lw-goal-browser-clock.txt --port 8002 # 不使用正式 data 目錄。
```

再執行完整 Chromium：

```bash
LIFEWORLD_TEST_URL=http://127.0.0.1:8002 LIFEWORLD_TEST_CLOCK_FILE=/tmp/lw-goal-browser-clock.txt .venv/bin/python -m pytest browser_tests -q --tb=short # 跨日案例只修改隔離服務時鐘，結束後恢復。
```

不設定時鐘控制檔時，跨日瀏覽器案例會明確標示跳過；其他一般流程仍可對 README 的正常隔離服務執行。此時不能將結果宣稱為完整 19 條通過。測試啟動器與時鐘控制不可部署到正式環境。

### 限制與交接

本輪未測 Safari、原生手機觸控、正式多裝置負載或雲端部署；沒有接入真實 AI、語音／OCR 或夜間關懷。建立草稿僅此裝置，瀏覽器清除儲存後不能恢復。舊資料的期限需要使用者補設定；不偷偷預填或結束舊目標。修改期限採延長，沒有縮短既有期限、恢復或複製歷史目標功能。
