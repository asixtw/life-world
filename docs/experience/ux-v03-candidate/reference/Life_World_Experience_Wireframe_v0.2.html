LIFE WORLD / DESIGN EXPLORATION

經歷記錄
低保真互動原型

一頁只處理一件核心事情。使用者先記錄生活，再補充目標與人物，最後檢查可修改的文字，確認後才真正更新世界。

切換測試身分
正式帳號：文字／拍照與影像／語音、可選 AI。
訪客：僅文字、無 AI、略過人物。
這是獨立 Wireframe，不是連線產品。所有 AI、圖片、音訊、保存草稿、確認與刪除均為 UI 示意，不會連接 API 或寫入資料庫。
建議頁面與流程
  1. 01記錄經歷
    只關注內容與素材
  2. 02記錄目標進度
    填寫活動數量或略過
  3. 03這次有和誰互動嗎？
    選擇既有人物或新增人物
  4. 04檢視並確認
    可編輯摘要、核對來源、正式保存
