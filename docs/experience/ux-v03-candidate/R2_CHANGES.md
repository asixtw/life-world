## 狀態／保護

- 關閉人物預覽保留核對選擇，不代表寫入。來源變動、取消候選與多人操作仍按每人key隔離。
- 候選的「已核對」與「能保存」分開：多人定向提交契約未接通、提及人物的資料更新不能冒用第一位參與者；此類資訊仍留B區。
- 只有操作「使用AI」且取得正確範圍授權才啟動**示意**整理；手動路徑示意請求也為0。實際API／外部網路請求始終0。
- AI回應期間原文變更、切手動或Owner改變，舊回應不得覆蓋內容。已手改摘要不被新示意回應直接替換，需要主動採用。
- 同一份示意草稿保存後重開會保留內容、來源重核對狀態與人物選擇；捨棄未保存修改不刪既有草稿。
