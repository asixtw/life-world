- [ ] 人物抽屜固定標題與底部「完成檢視」，中間獨立捲動；可保存與不寫入分區，能力警告不重複。
- [ ] 修改原文後保留人工摘要但要求重核對；AI候選依來源失效、有效手動資料盡量保留，未改原文不失效；不能未處理就確認。
- [ ] 整理方式單一選擇、預設手動；首次取得正確提供者／範圍／用途授權，同範圍有效不重問，背景AI不涵蓋未確認草稿，未選AI零模型請求。
