# 保留評估資料邊界

`inputs.v1.json` 有十五位人物各兩個新情境，共 30 題，只含 persona ID、prompt、source refs 與 `usageScope=demo`。`reference.v1.json` 依同一 ID 保存評分規則、可接受範圍、生成參考方向與待人工審查狀態。預寫劇場與前端不 import 參考檔；模型輸入不得合併該檔。同一事件改措辭不算獨立測試，後續真人研究須另按人物隔離並取得資料使用依據。

本輪未執行即時模型、微調或真人預測驗證；參考方向不是權威真值，須由人員核對原始來源。所有情境均為合成，不能作實際人物行為預測保證。
