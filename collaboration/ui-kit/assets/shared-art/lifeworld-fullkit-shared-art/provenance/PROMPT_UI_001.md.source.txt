# LW-UI-001／LW-ASSET-001｜歐桑完整 UI、美術與動效指令

日期：2026-10-28。**歐桑主責、Boyi 驗收產品／視覺、Jerry 審查技術整合。**Boyi 已確認同仁收到通知，本次為正式任務；成果尚未交付驗收。本版取代先交小樣等核准、圖片另期安排的舊工作邊界。

## 必讀與完整範圍

先讀[歐桑總入口](PROMPT_OUSANG_START.md)、[十三類美術／動效清單](ART_DELIVERY_SPEC.md)、[十五位模擬人物任務](PROMPT_SIMULATION_001.md)。兩包整合於同一個可啟動的獨立展示專案。

必交：設計基礎、完整按鈕／輸入／導覽／面板狀態、多模態／錄音 UI、轉場、App 圖示與代表縮圖、Lumi／世界、蛋全狀態、破蛋／孵化畫面、完成回饋、十五位頭像與三組封面。規格、格式、尺寸、事件與驗收依完整清單，不再把美術延後。

共用 App 資產是產品候選；十五位人物及三封面是測試／POC／封測示範包，正式版是否保留待評估。封測入口「人物劇場 → 情境體驗（示範角色）」僅為待確認方案，不在本任務擅改正式導覽或真實人物收藏。

## 工具與工作區

VS Code＋官方 Codex 擴充或可讀寫／執行專案的等價 IDE；用實際可用模型／推理與圖像工具，回報版本，不因 Pro 推定所有 API 可用。Dot 可整理目標、追蹤與核對證據，無存取權時不宣稱自動監控 IDE。

個人分支 `work/ousang-full-kit`，整包只放 `collaboration/ui-kit/`，可建立 Vite＋React＋TypeScript、鎖定檔、資料、資產、測試及文件；不改根目錄工具鏈、正式 App／DB／確認交易。沿用[色彩](../../app/static/tokens.css)、[樣式](../../app/static/styles.css)、[原圖對照](../PEOPLE_RESTORATION.md)及[流程狀態](FLOWS_AND_STATES.md)。
