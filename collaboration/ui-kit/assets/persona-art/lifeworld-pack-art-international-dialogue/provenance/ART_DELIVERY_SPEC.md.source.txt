# LW 完整 UI／美術／動效交付規格

日期：2026-10-28。**歐桑主責、Boyi 驗收產品／視覺、Jerry 審查元件／載入／事件及整合。**本輪一次完整交付，以下納入 LW-UI-001／LW-ASSET-001；成果尚未製作或驗收。歐桑交付前自行生成、預覽、修正、重測，不能以一次到位省略驗證或保證只生成一次即零瑕疵。

## 1. 視覺依據

沿用 [色彩](../../app/static/tokens.css)、[共用樣式](../../app/static/styles.css)、[人物／來源樣式](../../app/static/relationships.css)及 App 的 Lumi，溫暖、簡潔 2D，不另換品牌或角色。統一色彩、字體、間距、圓角、陰影、筆畫、焦點、日間／Quiet 與 motion tokens；新值有用途與對照。

## 2. 十三類必交清單

| 類別 | 本輪必交 |

| 1 設計基礎 | tokens／CSS 變數、字體／留白／版面、尺寸、圖示規則、日間／Quiet／減少動效與元件 API |

| 3 輸入 | 文字／長文／密碼／數字／日期時間／搜尋／下拉、checkbox／radio／switch；空白／填寫／錯誤／停用／載入／說明 |
| 4 導覽與卡片 | 四主分頁、tabs、返回／breadcrumb、人物／目標／故事卡、角色／標籤、統計／進度、排程格／星期快捷與選取 |

| 7 App 代表圖 | 主圖示、方形縮圖、分享圖、favicon；小尺寸、圓形／圓角裁切及明暗背景預覽，不依賴烤入文字 |
| 8 Lumi／世界 | 保留識別的姿勢、必要房間／世界基底、歡迎／陪伴／安靜／完成／錯誤退路視覺；不畫死亡或懲罰狀態 |

音效本輪仍為後期；動效不依賴音效才能理解，Quiet 無聲。聲音若另取得可列附加，不以未定音效工具阻擋這十三類。

**用途分流：**十五位人物與三組封面在 manifest 標 `demo`，供測試／POC／封測，正式版保留待評估；共用圖示、按鈕、蛋、Lumi 與動效標 `product_candidate`。封測入口提案見[總入口](PROMPT_OUSANG_START.md)，不是在這一包擅改正式導覽。

## 3. 蛋與回饋的規則

- 首次 Bio／目標建立並經後端確認後才出現 Lumi；fixture 明示條件，不提前以 Lumi 第一人稱說話。
- 破蛋是首次目標成立的呈現，不自行給分或完成終極成果；後續每顆目標蛋不自動重跑首次 Lumi 誕生。
- 真實進度／養分以唯一伺服器回執為準，元件只接展示資料／回呼；跳過、重播、關閉不改帳本。
- Quiet／減少動效提供立即靜態結果，動畫失敗仍可繼續；蛋、蛋殼、Lumi、光效有分層、錨點與尺寸資訊。

## 4. 格式與檔案交付

| 項目 | 必交格式／尺寸 |
|---|---|
| App 圖示 | 1024×1024 PNG 原稿；512／192／180／48 PNG 輸出；原生向量另交可編輯 SVG，不以包 PNG 的 SVG 冒充向量 |
| 代表縮圖 | 1200×630 分享圖、1024 方形主圖與裁切預覽；這是 Web／設計輸出，不宣稱已上架原生 App |
| 人物／情境 | 十五位 1024 方形頭像原稿與 256 顯示輸出、圓形裁切預覽；三組 1600×900 封面與較小版本；必要 UI 文字不烤進圖 |
| 蛋／Lumi／插畫 | 透明 PNG 原稿與顯示輸出；可編輯／分層來源（工具支援時），否則明示限制並交可組合圖層；尺寸／縮放／錨點 |
| 元件 | 真正 React＋TypeScript／CSS／SVG、typed props／回呼／狀態／主題；按鈕 PNG 不能代替互動元件 |
| 動效 | 可執行 CSS／SVG／React、狀態／duration／easing／loop／取消／完成事件；圖序則附實際 frames／atlas＋metadata；影片只輔助 |
| 清單 | assets/manifest.json＋可讀文件：id、路徑、類型、用途、尺寸／格式／大小、主題／狀態、來源／工具、版本、使用依據、alt、整合說明 |
| 工程交接 | 原始碼、鎖定檔、啟動與驗證命令、gallery／預覽、截圖、限制、Jerry 的接入說明 |

圖像工具製作插畫／頭像／封面；程式可原生製作 SVG 圖示／UI／動效。無圖像工具須明列阻礙、取得適當工具；提示詞／占位圖／空路徑不能標完成。生成圖附使用依據，未核對不宣稱已可任意商用。

全部在 `collaboration/ui-kit/`，原稿／優化版／展示圖分開；不提交 node_modules、API key、工具 session、私密人物資料或重複大型壓縮包。資產 ID 與實際檔案／展示一一對應。

## 5. 可操作展示與驗收

同一專案提供元件／狀態總覽、圖示／裁切、蛋全狀態、首次孵化、紀錄／錄音／附件／確認回饋、人物／劇場／來源、日間／Quiet／減少動效與轉場播放器；每項能點選／重播／切換，不需改程式才看狀態。

展示覆蓋登入、目標／排程、世界、紀錄／審閱／回饋、關係／人物／劇場、Quiet 的關鍵畫面構圖，以虛構 fixture 呈現；展示不冒充正式 App 已串接。
