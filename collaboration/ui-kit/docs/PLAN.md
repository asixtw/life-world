# Life World 獨立交付套件計畫

## 基準與邊界

- 共同起點：`1c9d502f32688bcc3c73e4b99a2cc3724c179047`；分支：`work/ousang-full-kit`。
- 本目錄為 React＋TypeScript 的隔離展示。只使用虛構 fixture；不讀寫正式 App、資料庫、人物收藏、經歷、進度或積分。
- 使用者已選 A：本套件採任務文件指定的三國／職務／哲學十五位；沈知衡等十五份原創長版卡現另附於 content/original-enthusiasts，不替代指定人物。人物與六場劇情已用固定 ID 寫入版本化 JSON。
- 即時 AI 端點、供應商和金鑰皆未指定。腳本模式可玩，adapter 接口可替換；無端點時顯示未設定。

## 使用情境與資料流

使用者在獨立展示中選擇場景與角色，查看來源後進入腳本對話，作出分支選擇，查看回顧並匯出有 `usage_scope=demo` 標記的紀錄。另可切換元件、Quiet、減少動效、孵化、錄音及附件的狀態展示。孵化只呈現已確認目標的回執，不產生回執。

輸入：版本化 persona、scenario、source、asset fixture，以及使用者當前的展示操作。輸出：本機頁面狀態和使用者主動下載的模擬紀錄。正式整合需由 Jerry 審查 adapter、資料生命週期與入口。

## 驗收清單

1. 三組各五位、來源與證據層級、四十五段多輪示例、三十個隔離評估情境；內容已寫入；仍待來源與美術人工審查。
2. 六場景各三條可達結束與回顧的不同路徑；選角、開始、返回、重設、來源、失敗、匯出。

4. 十三類元件與資產：設計基礎、按鈕、輸入、導覽卡片、面板、多模態、App 代表圖、Lumi、目標蛋、孵化、回饋、人物美術、轉場。
5. 1024 主圖示與規定衍生尺寸、1200×630 分享圖、十五位頭像與三組封面、透明蛋／Lumi 圖層；原稿、輸出、manifest 可對應。
6. 手機 390×844、桌面、鍵盤、長文、Quiet、減少動效、錯誤及返回操作驗證；測試與截圖只寫實際結果。
7. 鎖定檔、乾淨啟動、資產來源紀錄、Jerry 接入說明與交接表。

## 檔案結構

`src/` 為展示與型別；`content/` 為人物、劇情與來源；`evaluation/` 為保留情境；`assets/` 為原稿、顯示圖及 manifest；`tests/` 為契約與介面測試；`docs/` 為交接、驗證及來源說明。

## 正常、異常與邊界

- 正常：選擇→對話→回顧→匯出；已確認目標→孵化→完成定格。
- 異常：adapter 未設定、呼叫失敗／取消、錄音權限拒絕、附件失敗、動畫中斷；均保留可返回或重試操作。
- 邊界：切換人物或重設不得串 session，長文／窄螢幕不得遮住操作，Quiet 與減少動效可即時切換，跳過／重播孵化不得觸發正式計分。
