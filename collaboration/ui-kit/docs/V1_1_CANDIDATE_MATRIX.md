## 分批驗證

1. P0 日期純函式先紅燈再綠燈；檢查閏年、跨年、期間、星期快捷、時區；元件實測三行動互不覆蓋、未設期限不可安排、禁用日、鍵盤焦點、390×844／桌面。
2. P0 錄音／附件以可取消的 mock adapter 測權限拒絕、無裝置、格式／容量能力、明確上傳、失敗重試、晚回應、版本衝突、素材與原文保留；沒有實際服務時不顯示假成功。
3. P1 按取得的真素材做透明度、尺寸、左右殼、同房間日／Quiet、Lumi 無殼一般回饋、錨點與縮放；重測孵化、跳過、取消、重播、卸載、回執切換、減少動效。現有圖與新圖不可互相假冒。
4. P2 每個事件檢查兩候選及三格式的真檔、48kHz／峰值／大小／時長、Quiet 無聲、預設關閉、失敗不阻斷與同回執去重。
5. 每批在**該批最終程式**重跑 Vitest、TypeScript、Vite build，再以 kit 內互動和 390×844／桌面畫面留下命令、時間、截圖與限制。正式跨組、真 PG／AI、Safari／實機與 Boyi／Jerry 人工驗收均未執行，不得寫通過。
