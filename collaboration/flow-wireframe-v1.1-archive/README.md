# Life World｜完整流程 Wireframe｜封測 v1.1

日期：2026-10-29。獨立可操作原型，全部使用虛構資料，不連正式帳號、資料庫、API 或 AI。

**入口：[index.html](index.html)**，可以直接用瀏覽器開啟。建議在 Repository 根目錄啟動：

```bash
.venv/bin/python -m http.server 8011 --bind 127.0.0.1 --directory collaboration/flow-wireframe
```

開啟 `http://127.0.0.1:8011`；與實際 App 的 8000 埠服務分開。

## 完整動線

1. 稱呼 → 目標命名／成果與自選期限 → 三習慣月／週實際日期 → 核對 → 蛋／Lumi 示意 → 世界。
2. 記錄 → 文字／錄音／圖片／名片 → 整理或失敗後手動接手 → 分項確認 → 回饋 → 列表。未確認可保存草稿、刷新續作。
3. 收藏冊 → 摘要 → 人物 360° 三分頁／四維度／來源 → 小劇場或帶上下文記錄；交會沿故事換人物，按上一段返回。
4. 夜間設定 → 套用 23:40 示範時間 → 首次同意／拒絕 → 安靜輸入／靜態回饋；可改時段或切回。跨日補記以發生時間為準，不以建立時間代替。
5. 目標 → 修改安排／回顧 → 延長並檢視三習慣，或結束／選佐證確認成果 → 目標旅程。取消延長不改期限，下一目標不刪歷史。

「載入虛構示例」會重設本原型狀態，方便檢視人物流程；「清除本原型資料」另有確認。資料只在目前瀏覽器，沒有跨裝置同步。舊交接包及外層原型保留，不覆寫。

## 狀態與限制

- 「App 已實作對應能力」指正式 App 已有該類流程；**本頁全部操作仍是示範，不寫入 App**。規劃能力另標「規劃模擬」，不當作正式元件或 React 移植。
- 錄音包含拒絕、停止、試聽、重錄、上傳、辨識失敗與重試示意；沒有實際收音、播放、上傳或辨識。摘要為手動內容示意，未選 AI 供應商。
- 圖片／名片可預覽、移除或填虛構示例。原型預覽限 10 MiB；刷新後只保留檔名，圖片需重選，不宣稱已上傳。名片確認只建人物，不建經歷／見面或發獎。
- 人物統計、故事、飲食標籤為虛構示例；未知維度顯示尚未了解。私人筆記不改人物、進度或積分；訊息只供複製，不自動發送。
- 封測不做養分／積分等獎勵；本版不增加示範點數，已存在的舊欄位不刪。完整用量歷史、帳號、交易、權限與併發以實際 App／API 為準；正式 App 的舊獎勵仍需工程停用。
- 夜間時段與首次同意規則已確認；正式 App 夜間服務尚未實作。原型沒有通知、真實工作排程、麥克風或相機串接。

實測及未驗證項見當時的本機驗收紀錄。

## v1.1 私人多人物演練

人物劇場 → 勾選本人已建立人物（可一位或多位）→ 填情境、選來源 → 開始多人演練 → 指定回應對象／逐輪發言 → 結束回顧。人物卡的原四用途保留，並提供「加入其他人物一起演練」。返回／刷新保留當輪輸入與私人對話；建立新場前明示保留舊場次。

示範三組可組內多選，由目前選定角色回應，不加入真實人物庫；本原型仍是預寫示意，不是即時 AI、真人聊天室或歐桑完整角色包。正式資料權限、模型、來源選取與雲端保存仍待接入。封測規則依 當時 v1.1 基準第八節。
