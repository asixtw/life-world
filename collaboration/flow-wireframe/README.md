# Life World｜完整流程 Wireframe＋人物劇場 v0.5

更新：2026-10-30。入口：[index.html](index.html)。獨立 HTML／CSS／JavaScript 線框；全部為虛構資料，**不連正式 App、資料庫、AI、ASR 或圖片辨識**。可從人物劇場進入新版「建立我的情境」。

從儲存庫根目錄執行：

```bash
python3 -m http.server 8011 --bind 127.0.0.1
```

開啟 `http://127.0.0.1:8011/collaboration/flow-wireframe/`。也可直接用瀏覽器開啟 `index.html`；本機資料存於瀏覽器 localStorage，沒有跨裝置同步或私人資料安全承諾。

## 完整動線

1. 登入示意 → 稱呼 → 一個目標、三個習慣、月／週實際日期或每月第幾個星期幾 → 核對 → 世界與 Lumi。
2. 紀錄文字／錄音／圖片／名片 → 手動整理或模擬失敗 → 分項確認 → 保存／回饋。素材、辨識及登入均為線框模擬。
3. 收藏冊 → 人物摘要／360° → 來源；交會沿已確認故事切換人物，返回保留探索位置。
4. 人物劇場 → 建立我的情境 → 選已建立人物（單人 1v1／多人 C1）→ 目的 → 來源／假設預覽 → 對話 → 私下問 Lumi → 回顧與歷史。舊私人筆記與示範三組十五位角色仍有獨立入口。
5. 目標到期回顧 → 已完成紀念或曾經挑戰；夜間詢問與跨日補記仍可操作。

## 劇場 v0.5 核心規則

- 七種預寫行為：ANSWER、ASK_BACK、SILENCE、DEFER、CLOSING、EVADE、MONOLOGUE。沉默與服務故障分開顯示；測試控制可指定下一個模擬結果，**不屬正式產品介面**。
- 玩家可發言、旁聽、暫停、介入、結束。停止時只保存已展示發言；未展示台詞不算事件，回顧也不引用。已發生的供應商費用不能因取消而宣稱撤銷。
- Lumi 在私人頁面提供建議，不進角色對話；新場次不繼承舊場的虛構承諾。歷史可查看、刪除；正式人物、經歷、目標與積分均不變。
- 原型測試配置：1v1 八次／多人六次玩家行動；每段最多三則角色回應、Lumi 兩次、技術重試一次。**不是正式服務上限**；耗盡後只用已展示內容收尾。
- 沿用 PR #2 的 Lumi、房間、三組封面及十五張示範頭像候選；房間與文字、角色獨立。美術是候選資產，不等於 Boyi 已核准正式 App 視覺。

## 2026-10-30 原型操作修正

- 劇場每次發言與角色回覆後，自動讓發言欄留在可見區，對話清單捲到底；手機不用再從頁首往下找輸入框。在場真人只顯示姓名牌，不借用示範人物肖像。
- 習慣分成「自選日期／每週固定／每月固定」。每月是 **7 欄 × 4 列**，每格獨立選取，各週可選不同日子；勾「每月重複這份安排」套用整段挑戰，取消勾選只套用目前檢視月份，保留其他月份的安排。每格對應該月第幾個星期幾，不把月份硬算 28 天；**第 5 次不自動安排，使用者可在實際日曆補選**。舊版規律可轉成等價的前四週格子，已保存的實際日期不自動重算；重新套用時以目前選取為準。
- 每週星期按鈕與實際日期共用選取狀態；該星期在可編輯期間都已安排時反色，重整保留，點第二次取消同星期日期。手動修改會取消規律標籤、保留日期；進行中目標的每月規律只替換明天起的安排。
- 日曆明示挑戰起訖日；期間外日期顯示原因，建立時可直接調整三習慣共用的截止日。後續月份在期間內可選，切月及刷新保留選取。
- 空白底部導覽完整隱藏；有導覽時固定在視窗底部並保留捲動空間，避免攔住日期或最後一個按鈕。
- 首次目標建立後可點擊蛋，呈現微光、初裂、蛋殼分離及 Lumi 出現。可跳過、重播；刷新中斷時回到點擊起點，離頁清除計時器。Quiet／減少動效直接顯示靜態完成。動畫不重建目標或發獎；後續目標不再當成首次誕生。
- 記錄經歷時可搜尋並關聯多位既有人物、建立新人物草稿、逐位標示實際參與／僅被提及。取消及存草稿不建立人物；最後人工確認只建立／保存勾選的關聯。參與者進入交會，僅提及者保存在紀錄而不形成共同經歷；紀錄上的人物可連入人物卡。
- 記錄及校對頁可明確選擇目標、三習慣或已建立的後續活動任務；改選時取消先前投入確認。名稱與 ID 分開保存；沒選目標的紀錄 `goalId=null`，只關聯不等於投入。校對顯示實際活動名稱、數量與固定單位；進行中目標的期間外日期不採計，逾期目標的投入另留待回顧。後續任務有名稱及日期，建立後可在下一筆紀錄選取；封測仍不發積分／獎勵。
- 「C1」保留為規格中的內部概念，產品畫面改為「你與 N 位模擬人物／多人情境演練」，行為以中文標示。指定發言對象時由該人物先回應；示範角色保持獨立。
- 房間、Lumi、單顆目標蛋、孵化素材及導覽圖示沿用 PR #2 候選資產。新增分層檔來自 UI kit 的 `shared-art/lifeworld-fullkit-shared-art/exports/lw-egg-softglow-v1@512.png`、`lw-egg-initialcrack-v1@512.png` 與 `derived-v1_1/shells/shell-left@512.png`、`shell-right@512.png`，未重新生成圖片。
